# Конвертер КОМПАС

Программа для Windows: пересохраняет модели и чертежи **КОМПАС-3D** в формат более старых
версий (v16 и новее) **с сохранением дерева построения**, а также сохраняет их в **PDF**.

> В этом репозитории только готовые сборки. Исходный код закрыт.

## Скачать

Последняя версия — на странице **[Releases](../../releases/latest)**:

- **`KompasConverter_Setup_X.Y.exe`** — установщик. Права администратора не нужны. Добавляет
  ярлык в «Пуск» и пункты в контекстное меню Проводника.
- **`KompasConverter.exe`** — portable-версия, один файл без установки.

Программа сама проверяет обновления при запуске. Когда выходит новая версия, в окне
появляется кнопка **«Обновить»**.

## Возможности

- Сохранение в КОМПАС-3D v16 … (предыдущая версия относительно установленной). Копия
  кладётся рядом с исходником: `Корпус.m3d` → `Корпус_v18.m3d`.
- Проверка, что история построения сохранилась. Если нет — попытка каскадного
  пересохранения через промежуточные версии.
- PDF: чертежи и спецификации сохраняются в векторный PDF, модели — лист с изображением
  в изометрии.
- Папка показывается деревом с галочками: конвертируются только отмеченные файлы.
- Контекстное меню Проводника: ПКМ по файлу → «Конвертер КОМПАС» → нужная версия или PDF.
  Можно выделить сразу несколько файлов. Состав меню настраивается в программе.
- Интерфейс в стиле Windows 11, светлая и тёмная тема.

## Требования

- Windows 10/11, 64 бит.
- **Установленный КОМПАС-3D** (полноценная лицензия, не Viewer). Формат файлов КОМПАС
  закрыт: записать файл в старую версию с историей построения может только сам КОМПАС,
  программа управляет им через API. Без КОМПАС программа покажет версии файлов,
  но конвертировать не сможет.
